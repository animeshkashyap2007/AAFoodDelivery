# A&A Food Delivery

A&A Food Delivery is a full-stack food ordering web application developed as a BCA project using Angular, ASP.NET Core Web API, Entity Framework Core, and SQL Server. The application allows users to browse food items, manage their cart, place orders, download invoices, and track deliveries through an interactive map.

## Features

- User registration and login
- Browse food menu
- View food details
- Add and remove items from cart
- Checkout and place orders
- Order receipt and invoice download
- Live delivery tracking
- Order history
- Contact page
- Responsive user interface

## Installation

### Backend

1. Open the `AAFoodDelivery.API` project in Visual Studio.
2. Restore NuGet packages.
3. Update the SQL Server connection string in `appsettings.json` if required.
4. Run the project.
5. Swagger will open automatically.

### Frontend

Open a terminal inside the client project.

```bash
cd AAFoodDelivery.Client
npm install
ng serve
```

Open the application in your browser:

```
http://localhost:4200
```
